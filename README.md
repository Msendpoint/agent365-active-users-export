# Microsoft Agent 365 Active Users Export & Governance Toolkit

> PowerShell automation and SaaS dashboard integration to export, validate, and monitor Microsoft Agent 365 Active Users usage data for licensing and governance reviews.

## Overview

This PowerShell project was extracted from an article on [MSEndpoint.com](https://msendpoint.com) and is part of the professional automation portfolio.

### Quick Start

```powershell
# Clone the repository
git clone https://github.com/Msendpoint/agent365-active-users-export.git
cd agent365-active-users-export

# One-click install & run (checks prerequisites, installs modules, launches main script)
.\Install.ps1
```

## Tech Stack

PowerShell, Microsoft Graph, PHP

## Requirements

- PowerShell 7.0 or later
- Microsoft Graph CLI (if applicable)
- Appropriate administrative permissions
